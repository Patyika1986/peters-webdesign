# peters webdesign

Responsive Webseite für Peter Lakatos aus Nürnberg mit HTML5, CSS3 und JavaScript. Keine Build-Abhängigkeiten.

## Starten

`index.html` im Browser öffnen oder das Verzeichnis mit einem statischen Webserver ausliefern, zum Beispiel mit `python3 -m http.server 8000`.

## Dateien

- `index.html`: Leistungen, Referenz, Preise, FAQ und Kontakt
- `style.css`: responsive Gestaltung und Unterstützung für reduzierte Bewegung
- `script.js`: Mobilmenü und dezenter Parallax-Effekt
- `impressum.html` und `datenschutz.html`: Rechtstextentwürfe mit Platzhaltern

## Vor öffentlichem Einsatz

Die vollständige Geschäftsanschrift, gegebenenfalls Umsatzsteuer- und Registerangaben sowie tatsächliche Hosting- und Datenschutzangaben ergänzen und rechtlich prüfen. Der Einrichtungspreis wird individuell vor Beauftragung vereinbart.
